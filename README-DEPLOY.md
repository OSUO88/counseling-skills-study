# GitHub Pages 部署說明

此儲存庫包含「諮商技術互動學習」的靜態網站。推送到 `main` 後，GitHub Actions 會部署 `index.html`、`assets/dog-collection/` 和 `考選部來源/` 至 GitHub Pages。

在 GitHub 儲存庫的 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。部署完成後使用 HTTPS 網址瀏覽：

https://osuo88.github.io/counseling-skills-study/

考選部來源 PDF 會公開供網站連結使用；請勿在此儲存庫加入登入資訊或個人資料。
