# 考選部官方歷屆試題來源

本資料夾保存考選部「考畢試題查詢平台」公開的諮商心理師試題 PDF 與測驗式標準答案，供本學習網站核對題型、題號和答案。下載年度為民國 113、114、115 年，科目代碼 1101 至 1106；每年六科各有試題和測驗式答案，共 36 份基礎 PDF；另收錄 11 份更正答案，合計 47 份 PDF。114 年 1102 試題檔以科目名稱命名，其餘依年度與科目代碼命名。

- 1101 諮商的心理學基礎
- 1102 諮商與心理治療理論
- 1103 諮商與心理治療實務與專業倫理
- 1104 心理健康與變態心理學
- 1105 個案評估與心理衡鑑
- 1106 團體諮商與心理治療

官方平台：<https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx>

網站題庫標示原則：

- 網站 18 張圖鑑各有一筆近年代表考點索引，按 115、114、113 年排序，附官方試題與適用的答案／更正答案連結；這是代表題分類，不是全部試題逐題分類。每張圖鑑另有 1 題根據該考點改寫的選擇題，會連回原卷且不逐字重製。
- 每張圖鑑共 50 題選擇：1 題標示「考點改寫」，其餘 49 題是網站自編的「技巧練習」。
- 每張圖鑑的 5 題手寫練習與參考解答，依圖鑑內容和常見申論作答要求自擬；不是考選部公布的標準答案。官方申論題請回到原始試題 PDF 閱讀。

網站「近期考點導覽」和「國考考點索引」協助從近到遠挑選代表題；未列入索引的題目仍可在年度題本與答案 PDF 中查閱。更正答案以檔名含「更正答案」的 PDF 為準。

較早年度可在官方平台選擇民國 81 至 112 年、諮商心理師類科與相應科目。請以平台上的試題、答案及更正答案為準。
